# Law Use Case

This use case contains legal document and case-law scraping targets.

## Existing scraper applications

- `applications/curia` — Court of Justice of the European Union (CURIA) case-law content
- `applications/eurlex` — EUR-Lex legal and case-law documents

## Typical outputs

- Court judgments and opinions
- Legal metadata (titles, identifiers, dates)
- Generated PDFs and parsed metadata JSON files
