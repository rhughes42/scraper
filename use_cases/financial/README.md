# Financial Use Case

This use case identifies useful financial sources that can be added as scraper applications.

## Priority target sites

1. **SEC EDGAR**
   - Website: https://www.sec.gov/edgar/searchedgar/companysearch.html
   - Value: Company filings (10-K, 10-Q, 8-K, etc.) for financial case analysis

2. **Federal Reserve Economic Data (FRED)**
   - Website: https://fred.stlouisfed.org/
   - Value: Macro-economic time series for financial trend and risk context

3. **European Central Bank Data Portal**
   - Website: https://data.ecb.europa.eu/
   - Value: Euro-area rates, balance sheet, and monetary indicators

4. **UK FCA Warning List**
   - Website: https://www.fca.org.uk/scamsmart/warning-list
   - Value: Regulatory warnings and enforcement-related entities

5. **Companies House (UK)**
   - Website: https://www.gov.uk/government/organisations/companies-house
   - Value: Corporate filings and ownership signals for due diligence

## Recommended next application modules

- `applications/sec_edgar`
- `applications/fred`
- `applications/ecb_data`

These can follow `applications/template/` and then be listed under this financial use case.
